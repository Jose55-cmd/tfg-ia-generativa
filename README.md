**Autor:** Josemanuel Yanes Salcedo  
**Diplomado:** Inteligencia Artificial Generativa  
**Institución:** Instituto Universitario Nuevas Profesiones  

## Resumen del Proyecto
Este repositorio documenta la arquitectura técnica y el pipeline de producción para la generación de activos multimedia (Imágenes, Avatares y Video Cinemático) utilizando un stack tecnológico integrado de IA Generativa.

## Stack Tecnológico
- **Leonardo AI:** Generación de blueprints y texturización (Prompting técnico).
- **HeyGen:** Síntesis de voz y animación facial fotorrealista.
- **Digen:** Cinematografía generativa e interpolación de cuadros.

## Estructura del Repositorio
- `/prompts_metadata`: Registro de los prompts utilizados para cada caso de uso.
- `/config_logs`: JSONs de configuración exportados de los modelos.
- `/docs`: Documentación técnica complementaria.
